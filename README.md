# HTML 편집기

로컬 HTML을 왼쪽 코드와 오른쪽 미리보기로 편집합니다. 편집기 설치 폴더와 편집할 자료 폴더는 서로 달라도 됩니다. 자료를 편집기 폴더로 복사할 필요가 없습니다.

## 실행

Windows 탐색기에서 **HTML 파일 또는 폴더를 `Start-Editor.cmd` 위로 끌어 놓으세요.** 실행 파일을 두 번 클릭한 뒤 경로를 붙여 넣어도 됩니다. 열린 창을 유지하고 http://127.0.0.1:8787/ 에 접속합니다. 이 앱의 내장 브라우저나 일반 브라우저에서 사용할 수 있습니다. 종료는 실행 창에서 Ctrl+C입니다.

PowerShell에서도 실행할 수 있습니다.

```powershell
node .\server.mjs "C:\자료\홈페이지\index.html"
```

HTML 파일을 지정하면 해당 파일을 먼저 열고 같은 폴더의 HTML을 목록에 표시합니다. 폴더를 지정하면 `index.html` 또는 첫 번째 HTML을 엽니다.

실행 중에는 상단 **파일 열기**를 눌러 편집기 안의 파일 선택 창에서 다른 폴더의 HTML을 선택하세요. **상위 폴더**로 이동하거나 경로 입력란에 원하는 폴더·드라이브 경로를 붙여 넣고 **이동**을 누를 수 있습니다. HTML 파일을 선택하고 **열기**를 누르면 서버를 다시 실행할 필요 없이 파일 목록과 이미지·CSS·JS의 기준 폴더가 함께 바뀝니다. 취소하면 현재 편집 내용을 유지하며, 저장하지 않은 수정이 있으면 확인 후 전환합니다. 여러 탭에서 다른 폴더를 열어도 각 탭의 저장 위치는 유지됩니다.

여러 편집기를 동시에 실행해야 할 때는 PowerShell에서 포트를 바꿀 수 있습니다.

```powershell
$env:HTML_EDITOR_PORT = '8788'
node .\server.mjs "C:\자료\다른 홈페이지"
```

이 경우 http://127.0.0.1:8788/ 로 접속합니다. 기본 포트로 돌리려면 `Remove-Item Env:HTML_EDITOR_PORT`를 실행합니다.

## 편집과 저장

- 왼쪽 코드를 수정하면 0.25초 후 미리보기에 반영됩니다.
- **요소 선택**에서 화면을 클릭하면 해당 HTML/SVG 코드로 이동합니다. JavaScript로 만든 HTML 문자열과 고유한 문구도 추적합니다.
- **페이지 조작**에서 버튼과 애니메이션을 실행합니다. 코드를 바꾸면 미리보기는 처음부터 다시 실행됩니다.
- **파일 저장 / Ctrl+S**는 원본 HTML을 저장합니다. 이전 내용은 **자료 폴더의 `.html-editor-backups`**에 보관합니다. 외부에서 원본이 변경되면 덮어쓰지 않고 알려줍니다.
- **내려받기**로 현재 코드를 별도 HTML 파일로 보관할 수 있습니다. 편집기를 닫기 전에는 저장 또는 내려받기를 사용하세요.
- 파일 목록에서 같은 폴더의 다른 HTML을 선택하고, 구분선을 끌어 두 영역의 너비를 조절합니다. 파일 목록 위에 마우스를 올리면 자료 폴더 경로를 볼 수 있습니다.

## 사용할 수 있는 자료

UTF-8로 저장한 일반 HTML, HTML에 포함된 CSS/JavaScript, SVG·이미지를 사용하는 정적 페이지에 적합합니다. 선택한 폴더 내부의 상대 경로 자원을 불러옵니다. 상위 폴더(`../`)나 사이트 루트(`/`)를 전제로 한 자원 경로는 조정이 필요할 수 있습니다.

별도 CSS/JS 파일의 내용은 미리보기에 적용되지만 이 편집기에서 직접 수정하는 대상은 HTML입니다. React/Vue 소스, 서버 프로그램, 로그인·저장소·동일 출처에 의존하는 앱에는 별도 개발 환경이 필요합니다. 캔버스·WebGL처럼 직접 대응하는 HTML 문자열이 없는 요소는 상위 컨테이너로 이동합니다.

## 다른 컴퓨터로 가져가기

이 폴더를 복사하고 Node.js를 설치하면 사용할 수 있습니다. `node_modules`를 제외하고 복사했거나 Git으로 내려받았다면 편집기 폴더에서 `npm ci`를 한 번 실행하세요. Windows에서는 `Start-Editor.cmd`를 사용할 수 있으며, 다른 운영체제에서는 `node server.mjs "/path/to/project"`로 실행합니다. 로컬 자원만 사용하는 자료는 설치 후 인터넷 없이도 편집할 수 있습니다.

검증 명령: `npm test`. 서버는 127.0.0.1에서만 실행되며, 미리보기용 위치 정보는 원본에 저장되지 않습니다.
